# 🗂️ نسخه اصلی داده‌ها (فرمت .table)

این پوشه نسخه **اصلی و آرشیوی** داده‌های وب‌سایت را نگه می‌دارد.

## تفاوت با پوشه `src/data/`

| پوشه | کاربرد | فرمت |
|---|---|---|
| `src/data/` | **فعال** — وب‌سایت از اینجا محتوا می‌خواند | `.json` و `.md` |
| `workspace-data/` | **آرشیو** — نسخه اولیه همراه با طرح‌واره ستون‌ها | `.table` |

## چرا این پوشه وجود دارد؟

فایل‌های `.table` علاوه بر داده، **طرح‌واره ستون‌ها** (نوع داده، الزامی بودن، مقادیر مجاز) را هم نگه می‌دارند:

```json
{
  "fields": [
    { "field": "id", "type": "number", "required": true },
    { "field": "level", "type": "enum", "enums": ["حرفه‌ای", "پیشرفته"] }
  ],
  "data": [ ... ]
}
```

این طرح‌واره مرجع خوبی است وقتی می‌خواهید:

- بفهمید هر ستون چه نوع داده‌ای می‌پذیرد
- مقادیر مجاز فیلدهای `enum` را بدانید (مانند سطح دوره یا نوع مدال)
- داده‌ها را به یک دیتابیس واقعی (MySQL / PostgreSQL) منتقل کنید

## مهم

> ⚠️ ویرایش فایل‌های این پوشه **هیچ تأثیری روی وب‌سایت ندارد**.
> برای تغییر محتوای سایت، فایل‌های پوشه `src/data/` را ویرایش کنید.
