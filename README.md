# 🏹 وب‌سایت باشگاه تیراندازی با کمان ققنوس

**Phoenix Archery Club — Official Website**

وب‌سایت حرفه‌ای، مینیمال و مدرن باشگاه تیراندازی با کمان ققنوس؛ طراحی‌شده برای جذب ورزشکاران حرفه‌ای، قهرمانان و تیم‌های ملی.

---

## ✨ ویژگی‌ها

| ویژگی | توضیح |
|---|---|
| 🌐 زبان | فارسی کامل با چیدمان راست‌چین (RTL) |
| 🎨 رنگ‌بندی | سرمه‌ای تیره `#0B1A33` + سفید `#FFFFFF` + نقره‌ای `#C9D1DC` |
| ⚛️ فریم‌ورک | React 18 + Vite |
| 💅 سبک‌دهی | Tailwind CSS |
| 🎬 انیمیشن | Scroll Reveal با IntersectionObserver (بدون وابستگی خارجی) |
| 📱 ریسپانسیو | موبایل، تبلت و دسکتاپ |
| 🚀 بهینه‌سازی | Lazy Loading تصاویر + `decoding="async"` |
| 🔍 سئو | متا تگ‌های Title / Description / Open Graph / Twitter Card |
| 📞 تماس | شماره تلفن به‌صورت لینک `tel:` در **تمام** بخش‌ها |
| 💬 کامنت‌گذاری | تمام کدها به زبان فارسی کامنت‌گذاری شده‌اند |

## 🚀 اجرای پروژه

### پیش‌نیاز
- Node.js نسخه ۱۸ یا بالاتر

### نصب و اجرا

```bash
# ۱. دریافت پروژه
git clone https://github.com/rootdejavu/phoenix-archery-club.git
cd phoenix-archery-club

# ۲. نصب وابستگی‌ها
npm install

# ۳. اجرای سرور توسعه
npm run dev
# → http://localhost:5173

# ۴. ساخت نسخه نهایی
npm run build
# → پوشه dist/ آماده آپلود روی هاست

# ۵. پیش‌نمایش نسخه نهایی
npm run preview
```

## ✏️ ویرایش محتوا (بدون کدنویسی)

تمام محتوای سایت از کد **جدا** شده است. برای تغییر متن‌ها فقط فایل‌های پوشه `src/data/` را ویرایش کنید:

### تغییر شماره تلفن و اطلاعات تماس
فایل `src/data/site-settings.md` را باز کنید:

```
phone: 02188776655              ← فقط عدد لاتین (برای لینک tel:)
phone_display: ۰۲۱ - ۸۸۷۷۶۶۵۵   ← متنی که روی سایت دیده می‌شود
mobile: 09121234567
address: تهران، ...
```

> ⚠️ **مهم:** مقدار `phone` و `mobile` باید **فقط عدد لاتین و بدون فاصله** باشد، چون مستقیماً در لینک `tel:` استفاده می‌شود.

### تغییر مربیان، دوره‌ها، امکانات و افتخارات
فایل‌های JSON مربوطه در `src/data/` را ویرایش کنید. ساختار هر فایل با کامنت مشخص شده است.

### تغییر رنگ‌بندی
پالت رنگی در دو جا تعریف شده:
- `src/helpers.jsx` → آبجکت `C`
- `tailwind.config.js` → بخش `colors`

## 📞 لینک tel: در کدام بخش‌ها؟

طبق نیازمندی پروژه، شماره تلفن در **۶ نقطه** به‌صورت لینک کلیک‌شونده قرار دارد:

1. هدر (دسکتاپ) — `Header.jsx`
2. منوی موبایل — `Header.jsx`
3. دکمه اصلی هیرو — `Hero.jsx`
4. هر کارت دوره — `Programs.jsx`
5. بخش تماس با ما — `Contact.jsx`
6. فوتر — `Footer.jsx`

➕ به‌علاوه یک **دکمه شنّاور** که همیشه روی صفحه در دسترس است — `CallFab.jsx`

## ⚠️ نکته مهم درباره محتوای فعلی

محتوای موجود در `src/data/` **نمونه (placeholder)** است:

- شماره تلفن `۰۲۱-۸۸۷۷۶۶۵۵` و آدرس ولیعصر واقعی **نیستند**
- نام مربیان و افتخارات ثبت‌شده **ساختگی** هستند

پیش از انتشار عمومی، تمام این مقادیر را با اطلاعات واقعی باشگاه جایگزین کنید.
